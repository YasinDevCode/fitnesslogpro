# FitLog — Workout Library
Hi My name is yasin Ali- My project overview here---
FitLog is a modern workout library and daily workout planning
application built with Next.js, TypeScript and Tailwind CSS.

Technologies

- Next.js
- TypeScript
- React
- App Router
- Tailwind CSS
- DaisyUI
- Lucide React
- Context API
- LocalStorage
- REST API

Features

- Responsive workout library
- Dynamic workout details page
- Add workouts to today's plan
- Save workouts for later
- Five-workout daily limit
- Mark workout as done
- Remove workouts
- Live plan and saved counters
- Sort workouts by duration, calories and rating
- LocalStorage persistence
- Toast notifications
- Custom 404 page
- Responsive mobile/tablet/desktop UI
